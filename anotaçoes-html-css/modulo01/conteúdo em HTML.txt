ESTRUTURA BASICA DO HTML

<!DOCTYPE html>
<html lang="pt-br"
    <head>
        <meta charset="UTF-8">
        <meta name="viewport"
        content="width=device-width,
        initial-scale=1.0">
        <title>document</title>
    </head>
    <body>
        <h1>Olá, mundo!</h1>
    <body>
</html>

<!DOCTYPE html> == diz pro navegador que você vai desenvolver um site em html 5
<html lang="pt-br" == abertura do html e o lang="pt-br" é pra dizer que esse site vai ser em português br
<head> == cabeça(configurações)
<body> == corpo( onde fica o site)
<meta charset="UTF-8"> == faz seu site ser compativel com caracteres UTF-8 ou seja fa seu site ser compativel com assentoações e outras caracteris

<meta charset="UTF-8">
        <meta name="viewport"
        content="width=device-width,
        initial-scale=1.0">
faz com que seu site vai ser visualizada numa escala de 100,vai abriar padrao sem zoom alt ou zoom in
        <title>document</title> == vai ser o titulo do seu site
